# Панель трейдера

Котировки собираются сами, история копится в репозитории, портфель считается у тебя в браузере
и наружу не уходит.

## Как это устроено

```
GitHub Actions (2 раза в день)
   └─ collector/collect.py
        ├─ CoinGecko   крипта, цены в USD и RUB, изменения 24ч/7д/30д
        ├─ Stooq       акции США, фонды, товары, индексы (дневные свечи)
        └─ ЦБ РФ       курс USD/RUB
             ↓
      data/prices_daily.csv    история цен, растёт каждый день
      data/latest.json         свежий снапшот
             ↓
      index.html               панель: считает портфель прямо в браузере
```

**Почему сбор живёт в GitHub Actions.** У раннеров GitHub свободный интернет, а из облака Claude
и из шелла на Маке биржевые API закрыты сетевой политикой. Плюс данные сразу лежат в репозитории,
и Claude читает их напрямую по `raw.githubusercontent.com` в любом чате.

**Почему портфель считается в браузере.** Репозиторий публичный (иначе Claude не прочитает цены),
поэтому суммы, сделки и остатки не должны в него попадать. `portfolio.json` лежит рядом с панелью,
в `.gitignore`, и читается только твоим браузером. Кривая капитала каждый раз пересобирается
из журнала сделок и истории цен, хранить её не нужно.

## Файлы

| Файл | Что это |
|---|---|
| `universe.json` | список инструментов Wallet и привязка к источникам данных |
| `collector/collect.py` | сборщик, зависимостей нет, только стандартная библиотека |
| `collector/summary.py` | короткая сводка в лог Actions |
| `data/prices_daily.csv` | история цен: `date,symbol,asset_class,close_usd,close_rub,source` |
| `data/latest.json` | снапшот: цены, изменения, объёмы, курс |
| `index.html` | панель |
| `portfolio.example.json` | шаблон журнала сделок |
| `portfolio.json` | твой журнал, **в git не попадает** |

## Первый запуск

1. Двойной клик по `setup-trader-market.command`: положит workflow в `.github/workflows/`,
   создаст репозиторий, включит Actions и запустит первый сбор с историей за год.
   Если Finder не запускает файл, один раз выполни в Терминале:
   `chmod +x "setup-trader-market.command"`
2. Скопируй `portfolio.example.json` в `portfolio.json` и впиши свои сделки.
3. Открой `index.html`. Локально хватит:
   `python3 -m http.server 8080` в этой папке, потом `http://localhost:8080`.

## Как вести журнал

```json
{"date": "2026-09-17", "symbol": "BTC", "side": "buy", "qty": 0.00138, "price_rub": 6500000, "fee_rub": 90}
```

`side`: `buy` или `sell`. Средняя цена, P&L, веса и кривая капитала считаются сами.
Пополнения счёта пиши в `deposits`, вывод в `withdrawals`: без них доходность посчитается неверно,
потому что день пополнения будет выглядеть как рост.

## Ручные команды

```bash
python3 collector/collect.py --selftest    # проверка логики без сети
python3 collector/collect.py               # обычный сбор
python3 collector/collect.py --backfill    # догрузить историю за год (один раз)
python3 collector/collect.py --check       # показать, какие тикеры не разрешились
```

## Ограничения, о которых надо помнить

- **Пре-IPO** (SpaceX, OpenAI, Anthropic, Bending Spoons) публичной цены не имеют, их в панели нет.
- **Токенизированные акции** (AAPLx, TSLAx, SPYx) считаются по базовой бумаге. Цена в Wallet может
  отличаться на величину спреда и премии.
- **CoinGecko free** отдаёт около 30 запросов в минуту. Сборщик специально идёт медленно.
  Если добавится много монет, заведи бесплатный demo-ключ и положи его в секрет `COINGECKO_KEY`.
- Репозиторий публичный намеренно. Сделаешь приватным, и Claude перестанет читать котировки.
